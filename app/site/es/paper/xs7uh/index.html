Técnico: El lienzo

Un panorama interactivo de soluciones con los conceptos clave del libro blanco.

Abstract. Este documento reúne los distintos enfoques del libro blanco en una serie de lienzos interactivos. Cada escena es un diagrama bilingüe, basado en datos y descargable, con agentes animados y una descripción narrada. Consulte la arquitectura y llévesela para su propio desarrollo.
Como sostiene el documento sobre el Problema de la compresión, las descripciones escritas pueden resultar insuficientes frente a las simulaciones visuales para explicar conceptos complejos. Este documento reúne los conceptos principales en un único lienzo interactivo, con una pestaña por cada idea central. Navegue entre las grandes ideas, arrastre para desplazarse y use la rueda del ratón para ampliar; pulse Expandir para ver en pantalla completa.

"En lugar de preparar un informe escrito, una IA podría generar una simulación, una visualización o una interacción espacial que permita a quien toma decisiones relacionarse con el material de una manera diferente." · A partir de El problema de la compresión


## §01 Diseñado para llevarse

Cada arquitectura está respaldada por un registro JSON descargable, de modo que puede llevarse, editarse y reutilizarse. Cada escena es bilingüe y adaptable a dispositivos móviles, con una narración escrita y hablada.

Aunque se trata de visualizaciones sencillas, ayudan a contar la historia y nos preparan para simulaciones más complejas, que veremos en el siguiente documento.
